# Changelog

## 0.2.0

- The Diff Notes sidebar icon shows the number of open notes.
- Files in the Commits view show their git status letter, and files with open notes are marked with a note count.
- Notes have coloured status icons and richer hover tooltips.

## 0.1.0

First release.

- Add PR-style notes to local, unpushed commits and uncommitted changes, right in the diff editor.
- Commits and Comments views in the sidebar, with Group by Commit / File / None.
- Notes are marked as pushed or outdated, and follow files across renames.
- Jump between notes with Previous / Next (Alt+P / Alt+N).
- Copy notes as markdown, delete resolved, pushed or outdated notes, or auto-clear pushed ones.
